cascadia is running — this build doesn’t include the dashboard UI

The API is live on this port:

  • POST /v1/chat/completions, POST /v1/completions — OpenAI-compatible inference
  • GET /v1/models, GET /health, GET /metrics
  • GET /api/topology, GET /api/stats — cluster state as JSON

The web dashboard is compiled in behind the dashboard-embed cargo feature, which needs the SPA built first:

cd crates/cascadia-dashboard/web
npm ci && npm run build
cd ../../..
cargo build --release -p cascadia --features dashboard-embed

Add openvino to the feature list for real-inference builds. Prebuilt release bundles newer than v0.1.8 ship with the dashboard included.
