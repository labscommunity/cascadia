# Discoveries

Novel / surprising / undocumented findings from this autolab session. Format mirrors rainier's `DISCOVERIES.md`: short title, what was tried, what was found, why it's worth recording.

```

**Setup:** what hardware / model / config.
**Finding:** the headline number or qualitative result.
**Why this is worth saving:** why it isn't obvious from the docs / not on the first page of search.
**Source experiments:** experiments/<id>/, ...
```
