# Break the Sequential Dependency of LLM Inference Using Lookahead Decoding (arXiv:2402.02057)

**Year / venue:** 2024, ICML 2024.
**Headline claim:** Up to 1.8x on MT-Bench (single GPU), up to 4x with multi-GPU strong scaling on code completion.
**Mechanism:** Pure-algorithmic, no draft model. Frames autoregressive decoding as a Jacobi fixed-point system on multiple future tokens at once. Each step: (a) Jacobi-update a window of k future positions in parallel from the current model state (accept whatever converges via greedy match against the model's actual output); (b) cache the resulting n-grams in a pool; (c) at each new position, lookup matching n-grams in the pool as prediction candidates and verify them in parallel. Trades extra FLOPs/step for fewer total decoding steps. Compatible with FlashAttention.

**Intel applicability:** MEDIUM. The algorithm is hardware-neutral, but it requires running an attention pass with k extra "lookahead" tokens prepended at every step — i.e., the cost per step grows. On bandwidth-bound iGPU where the decode step is dominated by weight loading, those extra tokens can be roughly free. On the discrete Arc B580 the extra compute is more visible. No special kernel; works with any attention impl that takes a custom attention mask.

**Implementation cost:** MEDIUM. The Jacobi window manager and n-gram cache are pure Python (~500 lines). The harder part is plumbing variable-length sequences through OV IR — OpenVINO's static-shape KV-cache requires either re-export per window size or going to dynamic-shape PagedAttention.

**Open hypothesis it generates for us:** Lookahead's main win is *no draft model required*. On alpha (Lunar Lake iGPU with strict memory budget) we may not be able to fit base model + draft head; Lookahead is the only spec-decode option in that regime. Hypothesis: Lookahead gives 1.4-1.6x speedup on Llama-3-8B INT4 on alpha at batch=1, where we cannot afford the EAGLE/Medusa head footprint.
