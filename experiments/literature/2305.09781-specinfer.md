# SpecInfer: Tree-based Speculative Inference and Verification (arXiv:2305.09781)

**Year / venue:** 2023, ASPLOS 2024.
**Headline claim:** 1.5-2.8x for distributed LLM inference, 2.6-3.5x for offloading-based inference. Lossless.
**Mechanism:** Foundational tree-attention paper. Uses *multiple* small speculative models (or one model with diverse sampling) to produce a *tree* of candidate continuations, then verifies the entire tree in one parallel forward pass of the big LM via a custom mask that respects parent-child relationships. Verification success rate goes from 52-57% (sequence speculation) to 96-97% (tree speculation) because the tree explores more paths simultaneously. Introduces the now-standard tree-attention mask format that EAGLE/Medusa/Sequoia all reuse.

**Intel applicability:** HIGH. Tree mask is just a 2D boolean matrix passed to `ScaledDotProductAttention`. Already implemented in OpenVINO 2024.x for some models. Multi-draft variant (multiple small models) is a natural fit for tahoma's heterogeneous fleet — the draft can run on a CPU worker while the verifier runs on Battlemage.

**Implementation cost:** SMALL for single-draft tree verification (foundational primitive). MEDIUM for multi-draft cross-device variant.

**Open hypothesis it generates for us:** SpecInfer's offloading numbers (2.6-3.5x) are exactly the regime tahoma cares about — model too big for one device, drafting on a cheap node, verifying on the expensive one. Concrete experiment: run a Llama-3-70B (sharded across alpha + bravo) with a Llama-3-1B draft on an Intel laptop CPU. Hypothesis: ≥ 2x speedup over no-spec-decode in the same sharded setup, because we are limited by activation-relay latency between shards, and spec-decode amortizes that latency over multiple accepted tokens.
