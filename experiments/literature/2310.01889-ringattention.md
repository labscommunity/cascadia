# Ring Attention with Blockwise Transformers for Near-Infinite Context (arXiv:2310.01889)

**Year / venue:** 2023, ICLR 2024.
**Headline claim:** Sequences scaled "device-count times longer" than memory-efficient single-device transformers, with no extra communication overhead due to overlap with computation. Multi-million-token contexts demonstrated.
**Mechanism:** Distribute the sequence dimension across N devices. Each device holds 1/N of the queries, keys, and values. Attention is computed in N rotation steps: at each step, every device computes attention between its local queries and one block of K/V; meanwhile, the next K/V block is being sent to it from the neighbor in a ring. Communication is overlapped with computation, so as long as compute time per block ≥ communication time per block, the ring rotation adds zero wall-clock overhead. Combines with blockwise FFN to keep peak activation memory low.

**Intel applicability:** HIGH for tahoma's multi-device topology, but with a twist. The original paper assumes high-bandwidth NVLink-style interconnect — comm time is small. On a tahoma fleet (libp2p over Ethernet/Wi-Fi), comm time is much higher relative to compute. The *overlap* condition becomes hard to satisfy unless we're at very long context (≥32K) or very large per-device blocks. Still useful as a conceptual framework for distributed attention; the SocketConnection / measured-bandwidth fields in tahoma's topology graph are exactly what's needed to decide whether the overlap will work.

**Implementation cost:** MEDIUM-LARGE. Requires per-step P2P send/recv across the libp2p mesh, careful block sizing, and an attention kernel that takes external K/V blocks as inputs. Non-trivial, but architecturally clean once the message-passing primitive exists.

**Open hypothesis it generates for us:** For long-context document QA on a 2-node tahoma fleet (alpha + bravo over 1 GbE), Ring Attention is *only* worth it above a context length where (compute_per_block_ms ≥ activation_block_size_bytes / 125_MB/s). Compute the crossover point empirically and use it as the routing rule: < crossover → tensor-parallel attention, ≥ crossover → ring attention. Concrete experiment: measure crossover for Llama-3-8B-INT4 on alpha+bravo; expected to be in the 4K-16K context range.
