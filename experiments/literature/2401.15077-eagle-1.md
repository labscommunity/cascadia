# EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty (arXiv:2401.15077)

**Year / venue:** 2024, ICML 2024.
**Headline claim:** 2.7x-3.5x latency speedup, 2x throughput on Vicuna and LLaMA2-Chat (up to 70B), maintains output distribution. Single-GPU speculative-decoding baseline.
**Mechanism:** Instead of having the draft model autoregress at the token level, EAGLE adds a tiny single-layer transformer module that autoregresses at the *feature level* — specifically the second-to-top hidden state. The trick: predicting features one step ahead is unavoidably noisy because features encode multiple downstream tokens, so EAGLE feeds the draft head both the previous feature *and* the previous token (one step ahead of the feature it is trying to produce). This collapses the uncertainty and lets a very cheap draft accurately reconstruct what the big LM "would have done internally," which is then verified in parallel via tree attention.

**Intel applicability:** HIGH. The technique is hardware-neutral: it's a different draft-model topology and a tree-attention verification mask. No CUDA-specific kernels are required. Tahoma's worker can host the draft head as a tiny additional OpenVINO IR (single MLP + transformer block) co-resident with the verifier.

**Implementation cost:** MEDIUM. Need to: (1) train/distill an EAGLE head per supported base model (one-time, ~1 GPU-day per 7B), (2) export the head to OV IR, (3) implement tree-mask attention in the verify path. Rainier already has speculative decode with mask-based KV-cache rewind — the verification machinery is there; the new work is mostly the draft head and dynamic-tree token packing.

**Open hypothesis it generates for us:** On charlie (Battlemage Arc B580, ~456 GB/s HBM-class bandwidth), where Llama-3-8B is bandwidth-bound, an EAGLE head should give ~2-3x decode speedup at batch=1 because we still pay one verifier forward per accepted token. Hypothesis: speedup_charlie >= 0.6 * speedup_A100, because Intel Arc has comparable bandwidth-to-compute ratio to consumer NVIDIA. Worth testing on alpha (Lunar Lake iGPU, ~70 GB/s LPDDR5X) too — there bandwidth pressure is even higher, so EAGLE could net more.
